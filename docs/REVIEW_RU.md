# Ревью Retake, 8 октября 2026

Проверена исходная версия `2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1`.
Разделение на `core`, `map` и `editor` уже позволяет развивать режим по частям.
Ниже замечания о конкретном поведении и варианты его улучшения. Условное
расположение файлов в репозитории принято как данность; пути установки
ошибками не считаются.

## Ошибки, для которых предложены исправления

**P1** означает существенный сбой основной функции или риск потери данных.
**P2** означает более узкую ошибку или проблему на границе модулей.
Ссылки ведут на исходную версию, чтобы номера строк не менялись после правок.

| Приоритет | Сценарий и результат в исходнике | Предложенное исправление |
| --- | --- | --- |
| P1 | Редактор вызывает `parse` как `scanf`. AMXX ожидает пары «строковый буфер / его длина», поэтому обычные строки координат не проходят проверку количества и отбрасываются. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_editor.sma#L853-L903) | Общий строгий разбор чисел для загрузчика и редактора. |
| P1 | После смены карты редактор начинает с пустых массивов. Нажатие Save до ручного Reload открывает уже существующий файл с `w` и заменяет его пустыми секциями. [Загрузка редактора](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_editor.sma#L54-L76), [запись](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_editor.sma#L712-L742) | Первичная загрузка, проверка готовности, временный файл, проверка записи, резервная копия и откат при ошибке замены. |
| P1 | Таймер создаётся с ID `90000 + player_id`, а обработчик использует полученный ID как номер игрока. Проверка подключения не пропускает такой ID, поэтому нужного возрождения не происходит. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_core.sma#L281-L319) | Вычесть базовый ID, проверить диапазон и состояние; отменять задачу при выходе и переходе в наблюдатели. |
| P1 | Выбор спавна выполняется с повторениями. В комплектном INI только одна точка на команду/плент, поэтому два игрока одной команды получают одинаковые координаты. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_map.sma#L95-L123) | Резервировать точки до следующего раунда, учитывать вместимость карты и проверять пересечения точек. |
| P1, повреждённый конфиг | Размер стены `-64` проходит разбор. При построении габаритов минимум становится больше максимума; в ReHLDS это приводит к `Host_Error("backwards mins/maxs")`. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_map.sma#L255-L310) | Принимать только конечные числа; размер стены 1–4096, с проверкой до создания сущности. Это сценарий локального INI, удалённая атака не утверждается. |
| P2 | Подготовка создаёт `TASK_PREPARE`, но отменяет неинициализированный `g_task_prepare`. Если игрок вышел и вернулся до старого срока, старая задача видит новый флаг подготовки и запускает матч раньше нового отсчёта. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_core.sma#L159-L186) | Один постоянный ID задачи, удаление при каждой отмене и повторная проверка условий перед стартом. |
| P2 | После достижения счёта победы начинается разминка, но новая проверка условий не запланирована. При неизменном составе следующий матч не запускается. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_core.sma#L553-L574) | Повторно проверять условия после перезапуска разминки. |
| P2 | `retake_config_saved` объявлен и ожидается загрузчиком, но редактор его не вызывает. Изменённый файл и активные данные расходятся. [Контракт](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake.inc#L20-L22) | Отправлять событие после успешной записи; применять проверенные данные и возвращать матч в разминку. |
| P2 | Строка из шести нечисловых слов принимается за спавн: `str_to_float` даёт нули, а счётчик слов продолжает расти. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_map.sma#L319-L351) | Проверять полное преобразование каждого токена, количество, диапазон и конечность. |
| P2 | Загрузчик удаляет активные точки и стены до проверки нового файла и считает пустой файл готовым. Core не проверяет `retake_map_has_config`. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_map.sma#L125-L148) | Сначала разобрать и проверить новый набор, затем применить. Ошибка сохраняет прежний рабочий набор; старт требует готовой карты. |
| P2, внешний вызов | Недопустимый `slot` читается в `arr_spawn_count[slot]` раньше проверки границ. [Код](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_map.sma#L95-L102) | Проверка диапазона перед первым доступом; native возвращает 0. Штатный core передавал допустимые значения. |
| P2 | Старое меню редактора продолжает менять данные после выхода или отзыва прав. В списке стен второй администратор может сдвинуть индексы удалением, и первый удалит соседнюю стену. [Обработчики](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_editor.sma#L620-L650) | Повторная проверка прав и режима в каждом обработчике; стабильный ID стены. |
| P2 | Имена стен вроде `#cover` или `a=b` меняют смысл INI после сохранения. Длинный ключ также индексирует укороченный буфер по позиции `=` из исходной строки. [Имя](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_editor.sma#L160-L175), [ключ](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_editor.sma#L794-L802) | Проверка длины до копирования; запрет управляющих символов и разделителей INI в именах. |
| P2 | Редактор создаёт собственные физические стены поверх стен загрузчика, а выход отключает только noclip. [Создание](https://github.com/asurahater/astra_loh/blob/2f1a187b4c28eff7b30dcb14c2d7f1d3a0ad42b1/retake_editor.sma#L517-L550) | Физическими стенами владеет загрузчик; редактор создаёт несолидное превью на время редактирования. |

Дополнительно в core очередь заполняет свободные места на границе раунда,
состав команд считается по текущим игрокам, результат раунда учитывается
только после принятия движком. Размещение перенесено в обработчик после
появления игрока: больше не подменяется результат функции выбора спавна
произвольным номером сущности `1`.

## Проверка и её границы

Исходные три SMA с AMXX 1.10.0.5486 и ReAPI 5.29.0.358 компилируются:
core выдаёт 8 предупреждений несовпадения типов, editor — 10, map — 0.
Это полезный пример того, почему успешная сборка не доказывает корректность
работы с таймерами и файлами.

Итог локальной проверки исправлений:

- Все три плагина собраны общим `scripts/build.ps1` на AMXX 1.10.0.5486
  с ReAPI 5.29.0.358: ошибок и предупреждений нет.
- Пройдены 16 тестов автономного инструмента проверки INI.
- Комплектный `de_dust2.ini` принят с вместимостью 2 игрока и 2 стенами.
- Тот же файл с `--players 10` отклонён с объяснением нехватки позиций;
  ожидаемый код завершения 1.
- Проверены изменения, локальные ссылки документации и порядок событий
  первого появления/входа из очереди по исходникам ReGameDLL_CS.

Игровой сервер и реальные клиенты в рамках этого ревью не запускались.
Сценарии геометрии карты, физики стен, камеры наблюдателя и повторных матчей
нужно пройти по [SMOKE_RU.md](SMOKE_RU.md) до установки на основной сервер.

Сохранение через временный файл с резервной копией защищает от обычных ошибок
записи/переименования. Полная устойчивость к отключению питания между двумя
переименованиями не заявляется; `.bak` сохраняется для восстановления.
