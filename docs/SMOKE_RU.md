# Игровая проверка перед установкой

Выполнять на отдельном тестовом сервере с копией конфигов. Эти пункты пока
не отмечены как пройденные: локальная компиляция не проверяет поведение движка.
Подключить все три модуля с `debug`, сохранить версии AMXX/ReAPI/ReGameDLL,
команды `amxx plugins`, `amxx modules` и журнал ошибок.

## Игроки и раунды

- [ ] Один игрок выбирает Join: появляется в разминке. Выходит до срабатывания
  задачи, новый клиент занимает его слот: чужой таймер не возрождает нового.
- [ ] Новый клиент впервые входит через очередь: на старте раунда получает
  штатное начальное снаряжение; следующая обработка входа не создаёт второй
  спавн и не расходует ещё одну точку.
- [ ] Два игрока начинают отсчёт. Один выходит на пятой секунде и возвращается
  через секунду: проходит полный новый отсчёт, старый старт не срабатывает.
- [ ] При `retake_win_round 1` закончить матч. Состав не менять: после разминки
  начинается следующий матч.
- [ ] Третий игрок входит при комплектном конфиге 1×1: остаётся в очереди.
  Освободить место: он входит на допустимой границе раунда.
- [ ] Во время матча выбрать Spectator, затем Join: повторной жизни в текущем
  раунде нет, камера и меню работают, очередь содержит игрока один раз.
- [ ] На карте с достаточными точками проверить 5×5 и нечётный состав:
  дополнительные CT, уникальные позиции, нет пересечений и застреваний.
- [ ] Проверить режимы A/B, случайный, только A и только B; первый раунд
  чередования начинается на A. Проверить положение и направление взгляда.
- [ ] Изменить лимиты состава во время разминки и матча: невозможный состав
  не запускается, лишние участники корректно ожидают места.
- [ ] Проверить отклонённое/повторное событие конца раунда с другим плагином:
  счёт не увеличивается дважды.

## Конфигурация

- [ ] Перезапустить карту с существующим INI, открыть редактор и сохранить
  без предварительного Reload: точки и стены сохранены.
- [ ] Попробовать пустую секцию, слово вместо числа, NaN/Inf, лишний токен,
  размер стены 0/-64/4097, слишком длинный ключ и пересекающиеся точки:
  получена понятная ошибка, предыдущий рабочий конфиг остаётся активным.
- [ ] Превысить 32 точки/секцию и 64 стены: явная ошибка вместо молчаливой
  потери записей.
- [ ] Временно сделать каталог конфигурации недоступным для записи:
  Save сообщает об ошибке, исходный файл цел, событие применения не отправлено.
- [ ] Проверить обычное сохранение, повторное сохранение и резервную `.bak`.
  Отдельно испытать отказ переименования и восстановление старого файла.
- [ ] Успешно добавить точку, сохранить и начать следующий матч: новая позиция
  присутствует в активных данных загрузчика.
- [ ] Сравнить `retake_status` и `retake_map_status` с фактическим составом
  и количеством точек; после ошибки Reload значения остаются прежними.

## Редактор и геометрия

- [ ] Обычный игрок не открывает редактор. У администратора отозвать флаг `h`
  при открытом меню: старое меню больше не меняет данные.
- [ ] Выйти, умереть, возродиться и отключиться во время редактирования:
  noclip и превью корректно убираются, состояние нового клиента чистое.
- [ ] Два администратора открывают список стен; один удаляет стену:
  действие второго относится к выбранной стене либо отклоняется как устаревшее.
- [ ] Имена с разделителями INI отклоняются. Сохранить и перечитать допустимое
  имя с пробелами и кириллицей без изменения текста.
- [ ] Много раз открыть редактор, Reload, Save, Exit: количество физических
  стен не растёт. Превью не блокирует игроков; рабочие стены блокируют проход.
- [ ] Осмотреть все точки в игре: пол, лестницы, приседание, прострелы,
  видимость противника и направление взгляда. Проверить модель стены и её
  реальные габариты столкновения.

После успешного прогона приложить результаты к PR и отметить версии сервера.
Незапущенные сценарии оставить пустыми.
