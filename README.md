# Retake для CS 1.6

Основа режима ретейка: разминка, очередь игроков, выбор плента и позиции появления,
загрузчик конфигурации карты и внутриигровой редактор.

Автоматическая установка бомбы и выдача комплектов оружия пока не реализованы.
Варианты развития собраны в [плане](docs/ROADMAP_RU.md), результаты проверки
исходной версии и внесённые исправления — в [ревью](docs/REVIEW_RU.md).

## Зависимости и установка

- CS 1.6 с ReGameDLL_CS и ReAPI; сборка проверяется с ReAPI 5.29.0.358.
- AMX Mod X 1.10; воспроизводимая сборка использует 1.10.0.5486.
- Модуль AMXX `engine`.
- Модель `models/box.mdl`, на которую уже ссылаются исходники.

Структура файлов в этом репозитории условная. Пути к конфигам и модели в коде
сохранены.

Собранные плагины устанавливаются в `addons/amxmodx/plugins/`. Порядок в
`plugins.ini`:

```text
retake_map.amxx
retake_core.amxx
retake_editor.amxx
```

Конфиг карты: `addons/amxmodx/configs/retakes/<имя_карты>.ini`.
В приложенном `de_dust2.ini` по одной точке для каждой команды на каждом пленте:
это пример для **1×1**. Для 5×5 нужно минимум по пять непересекающихся точек
в каждой из четырёх секций. Реальный предел участников ограничивается и
`retake_max_players`, и количеством доступных точек.

При ручной компиляции положите `retake.inc` и `retake_config.inc` в каталог
include либо добавьте корень репозитория в пути поиска компилятора.
Компилируйте и обновляйте все три модуля вместе: интерфейс загрузчика расширен.

## Сборка и проверка файлов

На Windows с PowerShell и Python 3.10+:

```powershell
pwsh -File scripts/build.ps1
python -m unittest discover -s tests -v
python scripts/check_config.py de_dust2.ini
python scripts/check_config.py de_dust2.ini --players 10
```

Сборщик скачивает фиксированные версии зависимостей с проверкой SHA-256,
создаёт три `.amxx` и журналы в `build/`. Ошибки и предупреждения компилятора
прерывают сборку. Эти файлы и каталог `.toolchain/` не входят в Git.

Проверка комплектного INI без `--players` проходит и сообщает вместимость 2.
Последняя команда намеренно завершится ошибкой: пример не содержит точек
для 10 игроков. Проверка файла не проверяет наличие пола, стен или видимость
между позициями на реальной карте. Для однозначного редактирования инструмент
также отклоняет повторяющиеся секции и ключи; игровые загрузчики читают такие
записи последовательно.

## Управление

Игрок открывает меню обычной командой выбора команды. При входе во время матча
он остаётся наблюдателем в очереди до свободного места на следующем раунде.
Переход в наблюдатели убирает игрока из очереди и отменяет его таймер возрождения.

Редактор открывается через `/retake_editor` в чате или `retake_editor_open`
в консоли. Требуется флаг `h` (`ADMIN_CFG`). Команды:

| Команда | Действие |
| --- | --- |
| `retake_editor_save` | Проверить и записать конфиг с резервной копией `.bak` |
| `retake_editor_reload` | Загрузить файл заново; ошибка чтения сохраняет текущий черновик |
| `retake_editor_exit` | Завершить редактирование и восстановить движение |
| `retake_status` | В серверной консоли: состояние режима, очередь и вместимость |
| `retake_map_status` | В серверной консоли: готовность карты, точки и стены |

Успешная запись сообщает загрузчику о новом файле. При успешном применении
карты текущий матч возвращается в разминку. Ошибки применения записываются
в журнал AMXX, а предыдущая рабочая конфигурация остаётся активной.
Редактирование рекомендуется проводить на тестовом сервере: отдельного
режима обслуживания, который исключает администратора из матча, пока нет.

## Настройки

| Переменная | По умолчанию | Значение |
| --- | --- | --- |
| `retake_min_players` | 2 | Минимум участников для старта, от 2 до 32 |
| `retake_max_players` | 10 | Верхний предел, дополнительно ограничен конфигом карты |
| `retake_prepare_time` | 10 | Отсчёт перед матчем, 1–300 секунд |
| `retake_roundtime` | 45 | Длительность раунда, 1–3600 секунд |
| `retake_freezetime` | 5 | Время неподвижности в начале раунда, 0–60 секунд |
| `retake_win_round` | 13 | Побед до завершения матча, 1–1000 |
| `retake_plantsite_chooser` | 0 | 0: A/B по очереди; 1: случайно; 2: A; 3: B |

Числовые ограничения применяются при чтении настроек. Если минимум игроков
выше вместимости карты, режим остаётся в разминке; проверьте `retake_status`.
При нечётном составе дополнительный игрок попадает за CT, как и было задумано
в исходнике. Балансировкой команд занимается сам режим.

Плагин управляет `mp_roundtime`, `mp_freezetime`, `mp_buytime`, `mp_startmoney`,
`mp_round_infinite`, `mp_respawn_immunitytime`, `mp_forcerespawn` и
`mp_autoteambalance`. Проверяйте совместимость с другими режимами, ботами и
плагинами балансировки. Автоматическое восстановление этих настроек при
выключении режима пока не реализовано.

## Проверка на сервере

Сборка и проверка INI не заменяют игровой прогон. Пошаговые сценарии перед
установкой на основной сервер находятся в [списке проверок](docs/SMOKE_RU.md).
